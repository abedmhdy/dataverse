# DataVerse — Interactive Database Academy

אתר לימוד אינטראקטיבי לקורס **מערכות בסיסי נתונים**: שיעורים בעברית, עורך ER, מעבדת המרה לטבלאות, מעבדת אלגברה רלציונית ומעבדת SQL על מנוע SQLite אמיתי בדפדפן.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח את הכתובת שמודפסת (ברירת מחדל `http://localhost:5173`).

## בדיקות

```bash
npm test            # 140 בדיקות יחידה: אלגברה, SQL, ER, המרה
npm run test:e2e    # Playwright (Edge של Windows) + בדיקות נגישות axe בבהיר ובכהה
```

## מה יש

| חלק | מצב |
|---|---|
| פרק 1 — ER/EER | 9 שיעורים + מבחן מסכם, ווידג'טים אינטראקטיביים |
| סדנת ER | עורך חזותי מלא + 4 תרגילי שרטוט עם בדיקה והסבר |
| מעבדת המרה ER → טבלאות | שלבים 1–8, אפשרויות 8A–8D, עדכון חי |
| מעבדת אלגברה רלציונית | σ π ρ ∪ ∩ − × ⋈ * ÷ ℱ ⟕ ⟖ ⟗, שלבי ביניים, 10 תרגילים |
| מעבדת SQL | SQLite/WASM, הסבר שגיאות בעברית, שלבי עיבוד לוגיים, 12 תרגילים |
| פרק 2 — המודל הרלציוני | 4 שיעורים + מבחן מסכם |
| פרק 3 — אלגברה רלציונית | 6 שיעורים + מבחן מסכם, מגרשי ניסוי חיים בכל שיעור |
| פרקים 0, 4–8 | רשימות שיעורים ומקורות; שיעורים מלאים — בשלב הבא |
